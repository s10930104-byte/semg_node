Phase 1：需求收斂與競品拆解（本週優先）
明確定義系統需求：確立量測應用場景、通道數、取樣率、電池容量與目標續航時間，作為後續元件選型的唯一依據。

競品採購與拆解參考：視需求採購市售同類模組（如淘寶現成方案）進行拆解，分析其晶片配置與機構空間規劃（註：僅作架構參考，須依自身專案用途篩選，避免盲目照抄）。

Phase 2：核心硬體架構定案（MCU / BLE / IMU）
MCU 與 BLE 架構拍板：依運算需求與功耗預算，決定採用「BLE SoC 單晶片方案」或「獨立 MCU + 獨立 BLE 模組」。

通訊介面與腳位盤點 (Pinout)：確認 MCU 具備足夠通道數與硬體協議（SPI / I2C / UART / SWD），確保能同時掛載 ADS1292、IMU 與燒錄除錯介面而不衝突。

IMU 感測器選型：確認慣性測量單元型號與通訊介面（SPI 或 I2C），完成硬體規格鎖定（韌體演算法待硬體定案後再行開發）。

Phase 3：電源管理與類比前端規劃（Power & AFE）
電源控制器與 S0–S5 狀態機設計：選定 PMIC / 充放電管理 IC，並定義 S0（全速運作）至 S5（完全關機斷電）各階段的供電策略與喚醒條件。

LDO 電源軌配置 (Power Tree)：

規劃 小電流低雜訊 LDO 專供類比前端（ADS1292），確保訊號品質。

規劃 大電流 LDO 供應數位主控與 IMU 等高功耗周邊。

確認其餘次要邏輯電源直接沿用 BLE 模組內建 LDO（若 Phase 2 改採單晶片方案則統一由上述兩顆分配）。

ADS1292 前端防護修改：將輸入端靜電保護（ESD）改為類比訊號專用規格（低漏電流、低寄生電容），避免影響微弱生理訊號。

Phase 4：機構介面與人機互動確認（開板前 Final Check）
雙模式電極介面定案：

確認板端/外殼乾式電極接觸點配置。

選定外接導線 Connector 規格，支援拉線外接標準貼片式 ECG/EMG 電極。

自定義按鍵 (User Button) 配置：預留實體按鍵並接至具備中斷喚醒功能的 MCU GPIO，供後期韌體自定義功能（開關機、配對、事件標記等）。
